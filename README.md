# Password Strength Checker

## About
A beginner Python cybersecurity project that evaluates password strength using basic security criteria.

## Features
- Hidden password input using getpass
- Checks password length
- Detects uppercase and lowercase letters
- Checks numbers and special characters
- Gives a score out of 5
- Displays password strength (Weak, Medium, Strong)
- Provides suggestions to improve passwords
- Checks against a small list of common passwords

## Technologies Used
- Python
- Git
- GitHub

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

   python password_checker.py

## Disclaimer
This is an educational project. It uses basic rules and a limited common-password list and does not guarantee password security.
